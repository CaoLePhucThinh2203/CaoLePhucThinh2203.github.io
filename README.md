## Điểm nổi bật

- **Giao diện Alpine Dark Mode:** Thiết kế tương phản cao lấy cảm hứng từ hình ảnh núi tuyết đêm, tích hợp hiệu ứng gradient mượt mà.
- **Tối ưu hiển thị:** Tương thích tốt trên cả thiết bị di động, tablet và máy tính để bàn.
- **Tự động hóa CI/CD:** Hệ thống tự động cài đặt gói, biên dịch và xuất bản phiên bản mới nhất lên GitHub Pages khi có commit đẩy lên nhánh `main`.

## Hướng dẫn chạy trên môi trường Local

1. **Clone repository về máy:**
   ```bash
   git clone https://github.com/CaoLePhucThinh2203/CaoLePhucThinh2203.github.io.git
   cd CaoLePhucThinh2203.github.io
   ```

2. **Cài đặt các gói phụ thuộc:**
   ```bash
   npm install
   ```

3. **Chạy máy chủ phát triển:**
   ```bash
   npm run dev
   ```

4. **Biên dịch sản phẩm (Production Build):**
   ```bash
   npm run build
   ```
